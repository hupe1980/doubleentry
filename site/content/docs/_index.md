These pages explain how each guarantee is produced and — just as often — what it
deliberately does not claim. They are written to be read in order, but each one
stands on its own.

For the API surface itself, see the [reference on docs.rs](https://docs.rs/doubleentry).
This site covers the reasoning; docs.rs covers the signatures.
