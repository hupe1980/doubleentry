**Start** gets a ledger running, in memory and over a database. **Concepts**
is the bookkeeping model. **Reporting** reads the books back. **Operating**
keeps them in production. **Assurance** says why they can be trusted, and how
to check.

Every Rust block on this site is compiled and run in CI against the crate.
Signatures are in the [API reference on docs.rs](https://docs.rs/doubleentry).
